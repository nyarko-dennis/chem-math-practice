# French II - source extracts

Text extracted from the student's own PURC 102 (French II) lecture decks in
`electrical-engineering/` (Pentecost University, Faculty of Business
Administration). Ground truth for authoring the future `lib/french*` banks.

Syllabus topics: Greetings; Introductions; Numbers; Time; Family; Grammar;
Reading; Writing; Speaking. These decks are the Semester-2 practical units.

- `p1-faire-des-projets.txt` - Unit P1, "Faire des projets" (making plans):
  future tense, expressing intentions.
- `p2-faire-des-courses.txt` - Unit P2, "Faire des courses" (shopping): food
  vocab, quantities, prices, comparatives (plus/aussi/moins ... que).
- `p3-au-restaurant.txt` - Unit P3, "Au restaurant": ordering, menu vocab.

Note: content is in French (with occasional English glosses). Bank items should
preserve accents and mirror the deck's vocabulary/grammar focus. Deck references
to audio CDs/page numbers are from the print textbook and can be ignored.
