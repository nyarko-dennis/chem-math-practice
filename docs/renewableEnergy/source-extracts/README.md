# Renewable Energy - source extracts

Text extracted from the student's own course materials in
`electrical-engineering/` (Level 100 EEE, Pentecost University). Ground truth
for authoring/fact-checking the future `lib/renewableEnergy*` question banks.
The "Fundamentals and Applications of Renewable Energy" textbook (Kanoglu,
Cengel, Cimbala) is deliberately NOT extracted (copyrighted commercial text).

Syllabus topics: Intro; Solar; Wind; Hydropower; Biomass; Geothermal; Ocean;
Energy storage; Smart grid; Efficiency; Economics.

- `renewable-energy-deck.txt` - lecture deck by Isaac Kuma Yeboah. Legacy `.ppt`
  (47 MB, mostly images); text pulled from raw PowerPoint TextChars/TextBytes
  atoms because no `soffice`/`catppt` is available. Slide order is approximate
  and template boilerplate was stripped. ~8k words covering intro, renewable vs
  non-renewable, solar, wind, hydro, biomass, geothermal, ocean.

Coverage gaps vs syllabus (not in the deck): energy storage, smart grid,
efficiency, economics - author from general knowledge or request more source.
