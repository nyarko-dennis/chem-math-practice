# Environmental Studies - source extracts

Text extracted from the student's own intro lecture in `electrical-engineering/`.
Ground truth for authoring the future `lib/environmentalStudies*` banks.

NOTE: "Environmental Studies" is NOT on the official Level 100 EEE syllabus
(`Level100_EEE_Second_Semester_Courses_and_Topics.pdf`). The syllabus's 8th
non-STEM course is "Ethics of Hard Work". This extract exists because a source
PDF was provided; confirm with the student whether Environmental Studies is a
real course to build before authoring a bank.

- `intro-environmental-studies.txt` - "Introduction to Environmental Studies"
  (37-slide first-year lecture): definition, interdisciplinary scope, ecology &
  ecosystems, pollution & health, water/energy/resources, human impact,
  sustainability.

Available but NOT extracted: `Observation_and_Forecast_of_NO_2_Emissio.pdf` is a
research paper (NO2 emissions), too specialised/advanced for an intro bank.
